# Правила написания кода для проекта

## Используемые библиотеки и фреймворки
1. Zenject - для DI и отказа от наследования от MonoBehaviour, где это возможно.
2. PrimeTween - для анимаций (при необходимости)
3. New Input System (InputSystem_Actions.cs) - для ввода игрока

## CodeStyle
1. Открывающие фигурные скобки всегда ставятся с новой строки
2. Правила нейминга переменных: public - с большой буквы (Speed), [SerializeField] private - с маленькой (speed), private - с нижнего подчеркивания (_speed), константы - капсом (SPEED).

## Общие правила
Старайся писать код на основе ивентов, уменьшая связанность кода (вызывай методы другого класса напрямую, только если нужно получить результат от этого вывода).
Старайся отказаться от MonoBehaviour там, где это возможно, используя взамен интерфейсы Zenject.
Пиши достаточно простой и понятный код, без ненужных усложнений.
Пиши комментарии только там, где это действительно нужно, и только на английском.
